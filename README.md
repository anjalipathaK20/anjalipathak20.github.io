# Anjali Pathak — GitHub Pages portfolio

Files:
- index.html: complete website, including all styles. No installation or build needed.
- .nojekyll: tells GitHub Pages to serve the files directly.
- README.md: these instructions.

## Publish on Anjali's GitHub account
1. Sign in to the account that should own the website.
2. Create a PUBLIC repository named EXACTLY YOUR-USERNAME.github.io, replacing YOUR-USERNAME with that account's actual username.
   If Anjali's username is anjalipathaK20, use anjalipathaK20.github.io.
3. Extract this ZIP on your computer. In the repository, use Add file > Upload files.
4. Upload the extracted index.html, .nojekyll and README.md directly into the repository root. Do not upload the ZIP or a containing folder.
   If your file picker hides .nojekyll, create it using Add file > Create new file; enter .nojekyll as the name and commit it.
5. Commit to the main branch.
6. Open Settings > Pages. Under Build and deployment choose Deploy from a branch. Choose main and / (root), then Save.
7. Wait for the Pages deployment to finish. Settings > Pages will show the actual published URL.
   For a user repository named YOUR-USERNAME.github.io, the URL is https://YOUR-USERNAME.github.io/.
